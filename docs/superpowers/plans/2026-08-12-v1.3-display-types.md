# v1.3 displayType: timeline + video-grid 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为首页 explore 区新增 `timeline` 和 `video-grid` 两种 displayType,并把 demo 数据扩展到 6 个 module。

**Architecture:** 沿用现有 dispatcher 模式。`ExploreModules.astro` 加 2 个 dispatch case,新增 2 个子组件(`Timeline.astro` / `VideoGrid.astro`)。每个子组件接收 `highlights` 数组,内部各自定义 Props。点击行为复用 ExploreModules 的外层 `<a>`,子组件不含 `<a>`。

**Tech Stack:** Astro 5.18(static)+ Tailwind CSS 3 + 纯 `.astro` 组件(无 JS 框架)。测试用现有 Vitest,但本次不新增组件测试(理由见 spec §8.1)。

## Global Constraints

来自 spec `docs/superpowers/specs/2026-08-12-v1.3-display-types-design.md` 和 AGENTS.md:

- **硬规则 1**:所有 UI 文案来自 `src/locales/*.json`,组件零游戏专属字符串。
- **硬规则 2**:主题色只用 `bg-nav` / `text-nav` 等 token(映射 `var(--nav-theme)`)。badge 状态色(`bg-green-500/15` / `bg-red-500/15`)是已有例外,可沿用。
- **硬规则 10**:UI 不用 emoji。
- **三层架构**:新增组件在框架层(`src/components/`),游戏无关;数据在配置层(`src/locales/*.json`)。
- **trailingSlash: 'never'**:所有 URL 无尾部斜杠。
- **`<a>` 不能嵌套 `<a>`**:子组件内部不渲染 `<a>` 标签,点击行为由 ExploreModules 外层 `<a>` 提供。
- **图片必须有 `loading="lazy"` + `alt`**,且约束宽高防止 CLS(Lighthouse CLS 指标)。
- **JSDoc 是 displayType 字段语义的单一真相源**(spec §5.2),必须包含「何时用 + 字段含义 + JSON 示例 + 视觉描述」四元组。
- **不实现** comparison-table、`/updates` 路由、组件测试框架、独立 markdown 文档(spec §9)。

**已知现状(本次实现基于这些事实):**
- `src/components/home/ExploreModules.astro` 当前 4 个 dispatch case(line 49-52),外层每个 module 包一个 `<a class="card group block overflow-hidden p-5">`。
- `.card` class 定义在 `src/styles/globals.css:94`(`rounded-lg border bg-card ... hover:border-nav/50 hover:shadow-md`)。
- `bg-nav` / `text-nav` token 来自 `tailwind.config.mjs:21`(映射 `--nav-theme`)。
- `home.explore.modules` 现有 4 项(order 1-4),完整结构见 `src/locales/en.json`。
- `ja.json` 是另一个 locale,需要同步。
- sitemap 由 `@astrojs/sitemap` 从 `src/pages/` 自动生成,**不读 `en.json` 的 href**(已验证),所以 `/updates` 等不存在的 href 不会污染 sitemap。
- 命令:`pnpm typecheck` / `pnpm build` / `pnpm test` / `pnpm dev` / `pnpm lint`。

**Interfaces:**

- [ ] **Step 1: 创建 Timeline.astro(含完整 JSDoc + 实现)**

写入 `src/components/home/modules/Timeline.astro`:

```astro
---
/**
 * Timeline displayType — vertical timeline of dated/numbered events.
 *
 * 何时使用:版本更新日志、活动时间线、boss 发布顺序、赛季节奏等
 * 具有时序性的内容。
 *
 * highlights 字段:
 *   - label  (string, 必填): 时间点标识。可以是版本号(v2.5)、
 *            日期(2026-08-12)、或序号(Week 3)。
 *   - detail (string, 必填): 该时间点的事件描述。
 *   - badge  (string, 可选): 状态徽章(如 "Latest" / "Hot" / "Ended")。
 *            渲染规则与 CodeCards 一致:文本含 "expire"/"ended"(大小写
 *            不敏感)显示红色,否则绿色。
 *
 * JSON 示例(放在 src/locales/<locale>.json 的 home.explore.modules[]):
 *   {
 *     "order": 5,
 *     "name": "Update History",
 *     "description": "Major patches and events, newest first.",
 *     "href": "/updates",
 *     "displayType": "timeline",
 *     "highlights": [
 *       { "label": "v2.5", "detail": "New raid: Shadowforge released", "badge": "Latest" },
 *       { "label": "v2.4", "detail": "Rebalanced all S-tier weapons" }
 *     ]
 *   }
 *
 * 渲染效果:垂直时间轴。左侧一条竖线(border-muted),每项一个圆点
 * (首项用主题色 bg-nav,其余 bg-muted)+ label(粗体)+ detail
 * (muted 文字)+ 可选 badge(右上角)。
 *
 * 设计约束:
 *   - 零 <a> 标签(点击行为由 ExploreModules 外层 <a> 提供)。
 *   - 零 JS。
 *   - 主题色只用 bg-nav token;badge 复用 CodeCards 的状态色(已有例外)。
 */
interface Props {
  highlights: Array<{ label: string; detail: string; badge?: string }>;
}
const { highlights } = Astro.props;
---

<ol class="ml-3 border-l-2 border-muted space-y-3">
  {
    highlights.map((h, i) => (
      <li class="relative pl-4">
        <span
          class:list={[
            'absolute left-[-7px] top-1 h-3 w-3 rounded-full',
            i === 0 ? 'bg-nav' : 'bg-muted',
          ]}
          aria-hidden="true"
        />
        <div class="flex items-start justify-between gap-2">
          <div class="min-w-0 flex-1">
            <p class="text-sm font-semibold text-foreground">{h.label}</p>
            <p class="mt-0.5 text-xs text-muted-foreground">{h.detail}</p>
          </div>
          {h.badge && (
            <span
              class:list={[
                'ml-2 shrink-0 rounded-full px-2 py-0.5 text-[10px] font-medium',
                h.badge.toLowerCase().includes('expire') || h.badge.toLowerCase().includes('ended')
                  ? 'bg-red-500/15 text-red-700 dark:text-red-300'
                  : 'bg-green-500/15 text-green-800 dark:text-green-300',
              ]}
            >
              {h.badge}
            </span>
          )}
        </div>
      </li>
    ))
  }
</ol>
```

```astro
---
/**
 * Video-grid displayType — 2-column grid of video thumbnail cards.
 *
 * 何时使用:游戏视频攻略、实机演示、update trailer 等视频内容的
 * 首页入口。
 *
 * 关键设计:首页不 embed YouTube iframe(避免 iframe 拖累 Lighthouse,
 * 且 embed 会让用户在站内看视频时广告曝光归 YouTube)。本组件只渲染
 * 缩略图卡片,点击行为由 ExploreModules 外层 <a> 提供,跳转到 module
 * 的 href(通常是视频列表文章页 — 文章页里既有视频又有站内广告)。
 *
 * highlights 字段:
 *   - title     (string, 必填): 视频标题。同时作为 <img> 的 alt(a11y)。
 *   - youtubeId (string, 必填): YouTube video id,11 位字符(如
 *                "dQw4w9WgXcQ")。组件据此自动拼接封面 URL
 *                https://i.ytimg.com/vi/{id}/hqdefault.jpg,
 *                用户无需单独提供缩略图。
 *   - duration  (string, 可选): 视频时长(如 "12:34")。渲染为缩略图
 *                右下角的 badge。
 *
 * JSON 示例(放在 src/locales/<locale>.json 的 home.explore.modules[]):
 *   {
 *     "order": 6,
 *     "name": "Video Guides",
 *     "description": "Watch the best walkthroughs.",
 *     "href": "/guides/video-walkthroughs",
 *     "displayType": "video-grid",
 *     "highlights": [
 *       { "title": "Beginner Guide", "youtubeId": "dQw4w9WgXcQ", "duration": "12:34" },
 *       { "title": "Boss Fight", "youtubeId": "abc123xyz", "duration": "8:21" }
 *     ]
 *   }
 *
 * 渲染效果:2 列网格(窄屏 1 列),每张卡片是 16:9 缩略图 + 右下角时长
 * badge + 底部标题。
 *
 * 设计约束:
 *   - 零 <a> 标签(点击行为由 ExploreModules 外层 <a> 提供,避免嵌套)。
 *   - 零 JS。
 *   - <img> 必须 loading="lazy" + alt + aspect-video 约束(防 CLS)。
 *   - duration badge 用 bg-black/80 text-white(视频时长视觉惯例,
 *     YouTube 自身也这么做),不是主题色,符合规则。
 *
 * 已知局限(未来扩展):
 *   每张缩略图跳同一个 module href,不能跳各自的文章页。要支持每视频
 *   独立 href,需要统一改造 ExploreModules(让所有 displayType 外层
 *   都不包 <a>),并扩 schema 为 highlights[i].href。本次不做。
 */
interface Props {
  highlights: Array<{ title: string; youtubeId: string; duration?: string }>;
}
const { highlights } = Astro.props;
---

<div class="grid gap-2 sm:grid-cols-2">
  {
    highlights.map((h) => (
      <div class="overflow-hidden rounded-md border bg-card">
        <div class="relative aspect-video">
          <img
            src={`https://i.ytimg.com/vi/${h.youtubeId}/hqdefault.jpg`}
            alt={h.title}
            loading="lazy"
            decoding="async"
            class="h-full w-full object-cover"
            width="480"
            height="270"
          />
          {h.duration && (
            <span class="absolute bottom-1 right-1 rounded bg-black/80 px-1.5 py-0.5 text-[10px] font-medium text-white">
              {h.duration}
            </span>
          )}
        </div>
        <p class="truncate p-2 text-xs font-medium text-foreground">{h.title}</p>
      </div>
    ))
  }
</div>
```
